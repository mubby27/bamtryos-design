SDK Overview
Architecture, design philosophy, and module map

The BamtryOS SDK (@bamtry/sdk) is a fully typed TypeScript library that gives developers a single, unified interface for all BamtryOS capabilities — regardless of the target platform. One package, one API, five platforms: Android, iOS, Windows, macOS, and Linux.

🪪

DID creation, resolution, credential management, and device linking.

getBalance()send()buildTx()getHistory()
📦

Encrypted IPFS file upload, retrieval, sharing, and access control.
upload()get()list()share()delete()
🤖
os.agent
AI agent chat interface, transaction analysis, and portfolio insights.
chat()confirm()analyseTransaction()getInsights()
📱

dApp Store browsing, installation, permission management, and launch.
list()get()install()uninstall()getInstalled()
📡

Typed event emitter for real-time balance, transaction, and agent events.
on()off()once()
ℹ️
Type safety: The entire SDK is written in TypeScript with strict mode enabled. All public method signatures include JSDoc comments. Type definitions are bundled — no @types/ package needed.

Initialisation
BamtryOS constructor, configuration, and lifecycle
main.tsTypeScript
import { BamtryOS } from '@bamtry/sdk';

const os = new BamtryOS({
  network:      'mainnet',          // 'mainnet' | 'testnet'
  apiBase:      'https://api.bamtryos.com/v1',
  storageGateway: 'https://ipfs.bamtryos.com',
  ai: {
    enabled:    true,
    model:      'gpt-4o',           // passed to Azure OpenAI
  },
  chains: ['ethereum', 'polygon', 'solana', 'cosmos'],
  debug:        false,
});

// Initialise — resolves once WebSocket is connected and session is established
await os.init();

// Access SDK version
console.log(os.version); // '1.0.0'

// Graceful shutdown
await os.destroy();

os.identity
DID and credential management interface
async identity.create(options): Promise<DIDResult> ▼

Generates a new DID, stores the keypair in the platform TEE, creates the DID Document, pins it to IPFS, and registers the DID on-chain. Returns the created DID and its document.

Parameters
ParameterTypeRequiredDescription
options.pinstringRequired6-digit PIN used to encrypt the keystore entry in TEE
options.methodstringOptional'ethr' | 'sol' | 'key' | 'bamtry' (default: 'bamtry')
options.displayNamestringOptionalHuman-readable display name stored in DID Document
Returns — DIDResult
{
  did:         string;           // e.g. "did:bamtry:0x7f3A…"
  document:    DIDDocument;     // W3C DID Document
  ipfsCid:     string;           // CID of pinned DID Document
  txHash:      string | null;    // On-chain registration tx (null for off-chain methods)
}
async identity.resolve(did: string): Promise<DIDDocument> ▼

Resolves any supported DID to its W3C DID Document. Checks the local cache first (5-min TTL), then queries the BamtryOS resolver (IPFS + on-chain).

async identity.issueCredential(params): Promise<VerifiableCredential> ▼
Parameters

params.typesstring[]RequiredCredential type array — must include "VerifiableCredential"
params.claimsRecord<string, unknown>RequiredArbitrary JSON claims to embed
params.expiresAtDateOptionalExpiry date — omit for non-expiring credential
async identity.listCredentials(options?): Promise<VerifiableCredential[]> ▼
Parameters
ParameterTypeDescription

os.agent
AI agent chat and transaction analysis interface
async agent.chat(message, options?): Promise<AgentResponse> ▼
Parameters
ParameterTypeDescription
messagestringNatural language message from the user (max 2000 chars)
options.sessionIdstringContinue an existing conversation thread
options.streambooleanEnable token streaming via os.events (default: false)
Returns — AgentResponse
{
  sessionId:  string;
  reply:      string;
  action?:    AgentAction;    // present when agent proposes an on-chain action
}
AgentAction types
type AgentActionType =
  | 'TRANSACTION_PROPOSAL'  // send / swap / contract call
  | 'STORAGE_UPLOAD'         // upload a file to IPFS
  | 'APP_INSTALL'            // install a dApp
  | 'CREDENTIAL_REQUEST'     // request a verifiable credential
  | 'SETTINGS_CHANGE';       // change a user setting
async agent.confirm(sessionId, confirmed, pin?): Promise<ActionResult> ▼

Execute or cancel the pending action in a session. If confirmed = true, the action is executed (signing occurs inside TEE). If pin is omitted, the SDK triggers biometric prompt.

async agent.analyseTransaction(chain, rawTx): Promise<RiskAnalysis> ▼

Submits an unsigned transaction to the Transaction Agent for risk scoring. Returns a risk score (0–100), risk level string, and human-readable warnings.

Event System
Typed pub/sub for real-time updates
events.tsTypeScript
// Subscribe to transaction updates
os.events.on('transaction:update', (event) => {
  console.log(`${event.txHash} is now ${event.status}`);
});

// Subscribe to balance changes
os.events.on('balance:update', (event) => {
  console.log(`${event.chain}: new balance ${event.balance}`);
});

// Stream AI agent response tokens
os.events.on('agent:token', (event) => {
  process.stdout.write(event.delta);
});

// One-time listener
os.events.once('device:paired', (event) => {
  console.log('New device paired:', event.device.name);
});

// Remove listener
const handler = (e) => { /* ... */ };
os.events.on('transaction:update', handler);
os.events.off('transaction:update', handler);
EventPayload TypeTrigger
transaction:update{ txHash, chain, status, confirmations }Tx status changes on-chain
balance:update{ chain, address, balance, usdValue }On-chain balance changes detected
agent:token{ sessionId, delta }Each GPT response token when streaming
agent:completeAgentResponseAgent response fully assembled
device:paired{ device: DeviceInfo }New device successfully pairs via QR
notification:push{ title, body, data }Server-sent push notification
connection:lost{ reason }WebSocket disconnects — SDK auto-reconnects
connection:restoredvoidWebSocket reconnected successfully

Error Handling
Typed error classes and recommended patterns
error-handling.tsTypeScript
import {
  BamtryError,
  AuthError,
  WalletError,
  StorageError,
  AgentError,
  NetworkError,
} from '@bamtry/sdk/errors';

try {
  await os.wallet.send({ chain: 'ethereum', to: '0x…', amount: '10' });
} catch (err) {
  if (err instanceof WalletError && err.code === 'INSUFFICIENT_FUNDS') {
    // Show balance warning UI
  } else if (err instanceof NetworkError) {
    // Chain temporarily unreachable — retry with backoff
  } else if (err instanceof BamtryError) {
    // All SDK errors extend BamtryError
    console.error(err.code, err.message, err.requestId);
  }
}
Error ClassError CodesDescription
AuthErrorCHALLENGE_EXPIRED, SIGNATURE_INVALID, TOKEN_EXPIRED, PIN_INCORRECTAuthentication and authorisation failures
WalletErrorINSUFFICIENT_FUNDS, TX_SIMULATION_FAILED, TX_BROADCAST_FAILED, CHAIN_NOT_CONNECTEDTransaction and balance errors
StorageErrorACCESS_DENIED, CID_NOT_FOUND, UPLOAD_TOO_LARGE, ENCRYPTION_FAILEDIPFS storage operation errors
AgentErrorAI_UNAVAILABLE, SESSION_NOT_FOUND, CONTEXT_TOO_LONG, ACTION_CANCELLEDAI agent interaction errors
NetworkErrorCHAIN_UNAVAILABLE, API_UNREACHABLE, RATE_LIMITED, TIMEOUTTransport and infrastructure errors

dApp Integration Guide
How third-party developers integrate with BamtryOS
✅
WalletConnect compatible: BamtryOS supports WalletConnect v2, meaning any dApp that already supports WalletConnect works automatically inside the BamtryOS dApp browser without additional SDK integration.
dapp-integration.ts — Native BamtryOS dApp manifestJSON
{
  "bamtryManifest": "1.0",
  "id":           "com.example.mydapp",
  "name":         "My dApp",
  "version":      "1.0.0",
  "entryPoint":   "index.html",
  "permissions": [
    "wallet:read",         // Read wallet addresses and balances
    "wallet:sign",         // Request transaction signing (requires user confirm)
    "identity:read",       // Read DID and public credentials
    "storage:read"         // Access files user explicitly shares
  ],
  "supportedChains": ["ethereum", "polygon"],
  "category":     "defi",
  "auditUrl":     "https://example.com/audit-report.pdf"
}
